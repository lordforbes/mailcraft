- JMAP accounts now work in the desktop app and on the command line, not only in the browser: add one from File › Add Account › JMAP server, with the server's name and a token. Mailflare (a mail service on Cloudflare Workers) is supported: tick "This is a Mailflare server" and paste an app password made in Mailflare's Settings › App passwords; mail, moves and marks are kept in step, and sent mail reaches its Bcc recipients.
